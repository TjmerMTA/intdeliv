### 1.3. Движок на новый код (простой ≈ 1–2 минуты)

```

gh run list --workflow engine.yml -L 3 --json databaseId,status,headSha
gh run cancel <id запуска со статусом in_progress>
```

- `gh workflow run …` ставит новый запуск с кодом нового `main`. Он **заменяет** ждавший: у того в Actions будет
  «cancelled», это норма. Проверка: во втором `gh run list` у `pending`/`queued` запуска `headSha` равен новому `main`.
- `gh run cancel …` останавливает идущий запуск. Его шаг `final save` сохраняет базу в `data`, после этого стартует
  новый: `restore db` → сервер (миграции, раздел 2) → туннель → новый `api.json`.

  адрес опубликован в 17:41:37 — около 46 секунд. С отменой добавляется её обработка — считаю **1–2 минуты**

  очередь не теряется.
- Убедиться, что `final save` прошёл: в отменённом запуске шаг `final save` зелёный, в логе `persist: базу збережено`.
  **Не уверен:** что `final save` (`if: always()`) выполняется при отмене, я знаю из поведения GitHub Actions,
  в истории этого репозитория отмену идущего запуска не нашёл (смотрел последние 80). Если он не прошёл, новый запуск
  поднимет предыдущее 5-минутное сохранение: собранное за эти минуты соберётся снова, а опубликованное за эти минуты

## 3. Путь назад

**Когда:** новый движок не стартует (запуски падают), `::error::persist` в Actions, или клиентка не может работать,
а исправить вперёд быстро нельзя. Половинчатое состояние из 1.4 — **не** повод для отката, оно проходит
за минуты.

**Почему база возвращается раньше кода:**
- Ловушка из LESSONS (14.10): код старше перехода на `intdeliv.sqlite.gz.enc` новый формат не читает и стартует
  с **пустой** базой. Для `036d6ea` она не сработает (`persist.sh` тот же). Но: **не** откатывать дальше `036d6ea`,
  **не** нажимать «Re-run» у старых запусков в Actions (они берут свой старый код), **не** запускать ветку
  `permanent-tunnel`.
- Ловушка именно этого выпуска: после первого старта ключи-названия в базе — по **новым** правилам, а `036d6ea`
  считает ключи заявок по **старым**. Старый код на новой базе молча перестанет узнавать записи «по названию».
  Ещё ему неизвестны `meta:nameKeysV`, пометки и вставленная в админке сессия Della. Значит, старый код
