# IntDeliv — Della → Lardi (розширення Chrome)

Розширення кожні 90 секунд забирає свіжі заявки з Della, фільтрує їх (ціна від 8000 грн,
прямий замовник, кузов, області, стоп-слова), складає у власну базу (IndexedDB у браузері)
і автоматично публікує на Lardi-Trans через офіційний API — на два акаунти одразу.
Керування — в адмінці https://intdeliv.siteboosty.com/ (вона бачить розширення сама).

## Встановлення

1. Завантажте папку `extension/` на комп'ютер (весь каталог, не окремі файли).
2. Відкрийте в Chrome адресу `chrome://extensions`.
3. Праворуч угорі увімкніть **Режим розробника**.
4. Натисніть **Завантажити розпаковане** і виберіть папку `extension/`.
5. Закріпіть значок **ID** на панелі (іконка пазла → шпилька). Клік по ньому показує стан,
   кнопки «Відкрити адмінку» та «Синхронізувати зараз».

Після оновлення файлів натисніть ⟳ на картці розширення в `chrome://extensions`
і перезавантажте вкладку адмінки.

Розширення працює, поки відкритий Chrome (вкладку адмінки тримати відкритою не обов'язково).
Якщо ви увійшли на della.com.ua у цьому ж браузері, збір іде з вашою сесією.

## Де взяти API-токен Lardi

1. Увійдіть на lardi-trans.com тим акаунтом, від імені якого треба публікувати.
2. **Налаштування → API** (розділ для розробників) → створіть/скопіюйте токен.
3. В адмінці: **Налаштування → Акаунти Lardi** — вставте токен для «Акаунт 1», потім
   для «Акаунт 2» (повторіть з другим акаунтом), натисніть «Перевірити».
   Після збереження токен показується замаскованим (`••••1234`) — це нормально,
   повторно вводити не треба.

Режими публікації: **both** — кожна заявка йде на обидва акаунти; **roundrobin** — по черзі.
Пауза між публікаціями на один акаунт — 60 с, ліміт — 500 заявок на добу на акаунт
(змінюється в налаштуваннях).

## Тестовий режим (DRY RUN)

За замовчуванням увімкнено **DRY RUN**: розширення збирає та фільтрує заявки, ставить їх
у чергу, але **нічого не публікує на Lardi**. У журналі з'являються записи
`DRY RUN: would publish → Lardi «Акаунт 1»: Київ → Львів, …`, а в таблиці заявка
позначається як «dry» для кожного акаунта.

Якщо токен уже вставлено, у DRY RUN розширення все одно перевіряє, чи знайдуться на Lardi
місто та тип кузова: заявки, які не вдалося зіставити, отримують статус
«Потребує перевірки» — їх можна виправити вручну до запуску.

Коли результат влаштовує — вимкніть DRY RUN у налаштуваннях. Заявки, що чекали в черзі,
почнуть публікуватися по-справжньому з заданою паузою.

## Актуальність

Заявка стає неактуальною (сіра, 🚫), якщо минула дата завантаження, якщо її не видно
у видачі Della понад 6 годин (рахується, лише коли збір справді працював) або якщо її
видалили вручну. Неактуальні заявки автоматично знімаються з Lardi (переносяться в кошик).
Видалені вручну не повертаються при наступному зборі.

## Для розробника

- Без збірки та залежностей: `manifest.json`, `background.js` (service worker, ES-модулі),
  `bridge.js` (міст з адмінкою через `window.postMessage`), `lib/`.
- Тести: з кореня репозиторію `node --test tests/*.test.mjs` (Node 20+).
- Журнал роботи: адмінка → «Журнал», або консоль service worker у `chrome://extensions`.
